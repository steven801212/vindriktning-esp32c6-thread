# Phase 2 — Matter over Thread (v0.2.0-dev1)

[繁體中文](README.zh-TW.md)

This subproject moves onboarding from manual Thread-dataset injection to normal **Matter over Thread commissioning**.

## What this dev build exposes

- Air Quality Sensor (Matter device type `0x002C`)
- Air Quality = Good
- PM2.5 = 10 µg/m³
- Temperature = 25.00 °C
- Relative Humidity = 50.00 %

These are intentionally fixed test values. The purpose of `dev1` is to validate the complete Apple Home path before wiring the real VINDRIKTNING and SHTC3 drivers.

## Toolchain

This Matter branch deliberately does not reuse the Phase-1 PlatformIO/ESP-IDF 5.5 environment.

Validated target stack for this branch:

- ESP-Matter: `release/v1.4.2`
- ESP-IDF: `v5.4.1` (the version recommended by that ESP-Matter release)
- Target: `esp32c6`
- Transport: Matter over Thread
- Commissioning: BLE
- Wi-Fi: disabled
- OpenThread CLI: disabled

## Build outline

Set up ESP-IDF v5.4.1 and ESP-Matter `release/v1.4.2`, export both environments, then enter this `matter` directory.

Configure the XIAO ESP32-C6 target with both defaults files:

```bash
idf.py -D "SDKCONFIG_DEFAULTS=sdkconfig.defaults;sdkconfig.defaults.esp32c6" set-target esp32c6
idf.py build
idf.py -p COM4 flash monitor
```

If the board contains old Matter/Thread credentials from previous experiments, erase flash once before the first test:

```bash
idf.py -p COM4 erase-flash
```

Then flash again.

## Apple Home test

1. Keep a HomePod mini / compatible Apple Thread Border Router online.
2. Flash this firmware and keep serial monitor open.
3. On iPhone: Home → Add Accessory → More options / scan the Matter setup payload shown/generated by the Matter development tooling.
4. If using the standard ESP-Matter development credentials and they were not overridden by factory data, the common development passcode is `20202021` with discriminator `3840`.
5. Commission the device to Apple Home.
6. Watch serial output for `Matter commissioning COMPLETE`.
7. Check whether Apple Home exposes temperature, humidity, air-quality and PM2.5 information.

Apple Home may choose not to render every optional Matter concentration attribute in its UI. That does not by itself mean the Matter cluster is missing; Home Assistant / chip-tool can be used later to verify the raw PM2.5 cluster.

## Success criteria

`v0.2.0-dev1` passes when:

- iPhone discovers the accessory over BLE,
- Thread credentials are provisioned by Matter commissioning,
- the ESP32-C6 attaches to the existing HomePod Thread mesh,
- Apple Home completes Matter fabric commissioning,
- temperature/humidity/air-quality data are visible or readable,
- no manual Active Operational Dataset is copied into firmware.

## Security

Do not commit household Thread datasets, Network Keys, PSKc values, DAC private keys, or generated production factory-data images.
