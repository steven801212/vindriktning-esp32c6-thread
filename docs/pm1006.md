# VINDRIKTNING PM1006 UART integration

[繁體中文](pm1006.zh-TW.md)

This document captures the PM2.5 integration plan for the IKEA VINDRIKTNING retrofit.

## Design decision

The ESP32-C6 should **passively listen** to the particulate sensor UART rather than actively polling the sensor.

The original VINDRIKTNING MCU already polls the PM1006-like sensor and drives the stock fan/LED behavior. By tapping the sensor TX line, the ESP32-C6 becomes a second read-only data sink and does not need to interfere with the original control loop.

## UART frame

The protocol used by existing VINDRIKTNING implementations is:

- baud rate: `9600`
- frame length: `20 bytes`
- header: `0x16 0x11 0x0B`
- PM2.5 value: bytes 5 and 6, big-endian
- checksum: unsigned 8-bit sum of all 20 bytes must equal `0` modulo 256

PM2.5 extraction:

```text
pm25_ug_m3 = (frame[5] << 8) | frame[6]
```

## Recommended ESP32-C6 parser

Do not copy the original ESP8266 `SoftwareSerial + delay(15)` approach.

Use the ESP32-C6 hardware UART with a non-blocking parser:

```text
UART RX ring buffer
    ↓
search for 0x16
    ↓
collect exactly 20 bytes
    ↓
validate 0x16 0x11 0x0B header
    ↓
validate checksum
    ↓
extract PM2.5
```

Recommended diagnostics:

- latest raw PM2.5 value
- filtered PM2.5 value
- timestamp / age of last valid frame
- valid-frame counter
- checksum-error counter
- framing/header-error counter

A short moving average or EMA can be applied after protocol validation. Filtering must remain separate from the UART parser.

## Electrical interface: important

Do **not** connect the VINDRIKTNING sensor TX directly to an ESP32-C6 GPIO unless the actual board signal level has first been verified.

Published VINDRIKTNING measurements report approximately 5 V UART logic. ESP32-C6 GPIO belongs to a 3.3 V I/O domain, so this project will use level reduction on the RX path.

Simple resistor-divider option:

```text
VINDRIKTNING PM1006 TX
          │
         10 kΩ
          │
          ├──────── ESP32-C6 UART RX
          │
         15 kΩ
          │
         GND
```

For a 5 V source, the divider produces approximately 3.0 V at the ESP32-C6 RX input.

Only the sensor TX → ESP32-C6 RX path is required for the passive-listening design, so a bidirectional level shifter is not necessary.

## Fan behavior

The first hardware version should leave the original VINDRIKTNING fan control unchanged.

Existing experiments report that disabling the fan significantly distorts PM2.5 readings. Fan-control experiments should therefore be treated as a separate future feature, not part of initial sensor integration.

## Matter mapping

Validated PM2.5 values will feed the Matter PM2.5 Concentration Measurement cluster in `µg/m³`.

The overall Air Quality state should be derived separately from the raw PM2.5 value. IKEA's stock LED thresholds observed by the community are useful for comparison, but they should not automatically be treated as the final Matter Air Quality classification policy.

## Planned implementation order

1. Complete Matter-over-Thread commissioning with fixed test values.
2. Add ESP32-C6 hardware-UART PM1006 receive driver.
3. Validate frame header/checksum on real VINDRIKTNING hardware.
4. Compare PM2.5 values against the stock LED behavior.
5. Feed validated PM2.5 into the Matter cluster.
6. Add SHTC3 temperature/humidity.
7. Tune filtering and Air Quality classification.
