# VINDRIKTNING PM1006 UART 整合

[English](pm1006.md)

這份文件整理 IKEA VINDRIKTNING 改裝專案中 PM2.5 的硬體與韌體整合方式。

## 設計決策

ESP32-C6 應採用 **被動監聽** 粒子感測器 UART 的方式，而不是自己主動輪詢 PM1006。

VINDRIKTNING 原本的 MCU 已經會定期 polling PM1006-like 感測器，並控制原廠風扇與 LED。ESP32-C6 只要旁聽感測器 TX，就能成為第二個唯讀 data sink，不需要介入原本控制迴路。

## UART frame

現有多個 VINDRIKTNING 實作採用相同協定：

- baud rate：`9600`
- frame 長度：`20 bytes`
- header：`0x16 0x11 0x0B`
- PM2.5：byte 5、6，big-endian
- checksum：20 bytes 以 unsigned 8-bit 相加後，modulo 256 必須為 `0`

PM2.5 解析：

```text
pm25_ug_m3 = (frame[5] << 8) | frame[6]
```

## ESP32-C6 parser 設計

不直接沿用早期 ESP8266 的 `SoftwareSerial + delay(15)` 寫法。

ESP32-C6 應使用 hardware UART 與非阻塞 parser：

```text
UART RX ring buffer
    ↓
尋找 0x16
    ↓
固定收滿 20 bytes
    ↓
驗證 0x16 0x11 0x0B header
    ↓
驗證 checksum
    ↓
取出 PM2.5
```

建議保留以下診斷資訊：

- 最新 raw PM2.5
- filtered PM2.5
- 最後一個有效 frame 的時間／資料年齡
- valid-frame counter
- checksum-error counter
- framing/header-error counter

moving average 或 EMA 放在 protocol validation 之後處理，filtering 不應和 UART parser 綁死。

## 電氣介面：重要

**不要直接把 VINDRIKTNING 的 sensor TX 接到 ESP32-C6 GPIO**，除非先實測確認該台機器的訊號電壓。

其他 VINDRIKTNING 實測資料指出這條 UART 約為 5 V 邏輯；ESP32-C6 是 3.3 V I/O domain，因此本專案預設在 RX 路徑做降壓。

簡單分壓方案：

```text
VINDRIKTNING PM1006 TX
          │
         10 kΩ
          │
          ├──────── ESP32-C6 UART RX
          │
         15 kΩ
          │
         GND
```

5 V 輸入經過此分壓後約為 3.0 V。

因為正式設計只需要 sensor TX → ESP32-C6 RX，被動監聽不需要 ESP32-C6 對 PM1006 發送資料，所以不必使用雙向 level shifter。

## 風扇

第一版保留 IKEA 原本的風扇控制，不改風扇供電或 duty cycle。

既有 VINDRIKTNING 實驗顯示，完全停掉風扇會明顯影響 PM2.5 讀值。因此風扇改造應視為後續獨立功能，而不是第一版感測器整合的一部分。

## Matter mapping

通過 header/checksum 驗證的 PM2.5 值會寫入 Matter PM2.5 Concentration Measurement cluster，單位使用 `µg/m³`。

Matter 的 Air Quality 等級應另外由 PM2.5 值計算。社群觀察到的 IKEA 原廠綠／黃／紅門檻可拿來比較，但不直接當成最後的 Matter Air Quality 分級政策。

## 實作順序

1. 先用固定假資料完成 Matter-over-Thread commissioning。
2. 加入 ESP32-C6 hardware-UART PM1006 RX driver。
3. 在真實 VINDRIKTNING 上驗證 header/checksum。
4. 對照原廠 LED 與 PM2.5 數值。
5. 將 PM2.5 寫入 Matter cluster。
6. 加入 SHTC3 溫度／濕度。
7. 最後再調整 filtering 與 Air Quality classification。
